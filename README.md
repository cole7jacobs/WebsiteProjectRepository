## About

This website was created for my ISDS 4125 Analysis and Design of Information Systems course at LSU. The goal of the project was to create a professional personal website using an AI coding agent while also learning how to use Git and GitHub throughout the development process.

The website includes three pages:

- **Home** – An overview of my education, experience, skills, honors, and contact information.
- **Resume** – A more detailed overview of my academic and professional experience.
- **Project** – A case study about a simulated federal IT risk and controls assessment I completed during my Technology Risk internship.

## What I Learned

One of the biggest things I learned from this project was how important it is to be specific when directing an AI coding agent. When I first started using Antigravity, some of its changes included information or design choices that I did not necessarily want. As I continued working on the site, I got better at telling the agent exactly what I wanted changed, what I wanted to keep the same, and what information it should not add. I also learned that it is important to review the agent's work instead of automatically accepting everything it creates.

I also learned how Git and GitHub can be used throughout the development process. Before this project, I did not have much experience using Git to track changes. During the project, I learned how to make changes locally, review them before committing, create commits for different stages of development, and push those changes to GitHub. This made it easier to see how the website developed over time and helped me understand the purpose of version control.
